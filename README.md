I'm Abel Ardhana Simanungkalit, but you can call me Dhana or Abel.
I'm a software engineer from Makassar with **6+ years of building web applications**, mostly with **PHP/Laravel** and **JavaScript**.
I started as a full-stack developer on education and government projects, and I've spent most of my career in **healthcare technology**.
Today I work as **Product Owner & Tech Lead** for **SyncMed RS**, a multi-tenant hospital information system (SIMRS) used by hospitals and clinics across Indonesia, and I still keep my hands on the code and the architecture.

I've integrated national healthcare platforms such as [FHIR (HL7)](https://hl7.org/fhir/), [SATUSEHAT](https://satusehat.kemkes.go.id/platform/docs/id/playbook/), and [BPJS](https://dvlp.bpjs-kesehatan.go.id:8888/trust-mark/portal.html) (PCARE & Antrean).
I enjoy contributing to open-source projects, engaging in discussions, and collaborating with fellow developers.

-   Built SIMRS modules end to end: requirements, database design, forms, frontend, query tuning, and reporting.
-   Refactored a microservice-based SIMRS for better UI reactivity and page load times.
-   Designed a media storage migration to open-source object storage, per-tenant activity log services, and a Telegram notification fallback for WhatsApp.
-   Set up **Jenkins** pipelines per service and wrote ~20 engineering SOPs (Git branching, PR review, unit testing, secure coding, migrations & rollback, hotfix SLAs).

**🤖 AI-assisted engineering**

**🌐 On-site IT infrastructure**
